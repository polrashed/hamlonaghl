🚚 ساخت خودکار DoustanTransport.exe

با GitHub Actions، فایل اجرایی روی یک ماشین واقعی Windows ساخته می‌شود؛ نیازی به نصب Python در رایانهٔ شما نیست.

۱فایل‌ها را در مخزن قرار دهید

ZIP را Extract کنید و محتویات پوشهٔ DoustanTransport را داخل مخزن GitHub بارگذاری کنید. فایل‌ها باید در ریشهٔ مخزن باشند: app.py، assets/، requirements.txt و .github/workflows/build.yml.

هنگام بارگذاری، وجود پوشهٔ مخفی .github را کنترل کنید؛ این پوشه محرک ساخت خودکار است.

۲اجازه دهید GitHub برنامه را بسازد

پس از ثبت فایل‌ها روی شاخهٔ main یا master، ساخت خودکار آغاز می‌شود. در GitHub به تب Actions بروید و اجرای Build DoustanTransport for Windows را باز کنید. علامت سبز یعنی ساخت موفق بوده است. همچنین می‌توانید در همان Workflow گزینهٔ Run workflow را بزنید.

۳دانلود فایل اجرایی

در صفحهٔ اجرای موفق، پایین صفحه به بخش Artifacts بروید، DoustanTransport-Windows را انتخاب و فایل ZIP را دانلود کنید. آن را Extract کنید تا DoustanTransport.exe را ببینید.

۴لینک پایدار در Releases (اختیاری)

یک Tag با نامی مانند v1.0.0 بسازید و به GitHub ارسال کنید. Workflow علاوه بر Artifact، خودکار فایل EXE را به Release مربوط به آن Tag پیوست می‌کند؛ لینک مستقیم دانلود در صفحهٔ Releases مخزن قرار می‌گیرد.
