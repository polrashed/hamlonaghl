# Doustan Transport — نسخه ۳

ابزار دسکتاپ فارسی برای تحلیل سه ورودی اکسل ناوگان، داپ/بارنامه و تراکنش سوخت.

## اجرای برنامه
1. ویندوز: Python 3 نصب کنید و گزینهٔ **Add Python to PATH** را فعال کنید.
2. پوشه را از حالت ZIP خارج کنید؛ فایل‌ها باید همین‌جا کنار `app.py` باشند.
3. `run.bat` را دوبار کلیک کنید. در اجرای نخست، وابستگی‌های `openpyxl` و `Pillow` نصب می‌شوند.
4. سه فایل اکسل موردنیاز را در برنامه انتخاب و تحلیل را اجرا کنید.

## ساخت فایل اجرایی
1. `build_portable.bat` را اجرا کنید (اتصال اینترنت برای نصب PyInstaller لازم است).
2. خروجی در `dist/DoustanTransport.exe` ساخته می‌شود؛ آن را روی ویندوز آزمایش کنید.

## رفع خطا
`FIX_CRASH.bat` نسخه‌های سازگار NumPy و openpyxl و Pillow را دوباره نصب می‌کند. برای مشاهدهٔ خطا، برنامه را از `run.bat` اجرا کنید.

## ستون‌های ورودی
نام دقیق ستون‌ها بسته به خروجی سامانهٔ مبدأ ممکن است تفاوت داشته باشد؛ عنوان‌ها باید در ردیف سربرگ باشند.
- **فهرست خودرو/VIN:** پلاک، سریال پلاک، VIN، PAN/کارت سوخت و مالک/راننده (در صورت وجود).
- **داپ/بارنامه:** شماره بارنامه، تاریخ، پلاک و سریال، مبدا/مقصد، وضعیت، مسیر، مسافت، راننده، کالا و نوع خودرو (هرکدام که موجود است).
- **تراکنش سوخت:** تاریخ و ساعت، VIN یا PAN، مقدار لیتر، جایگاه و محدوده/منطقه (مطابق فایل مبدأ).

برنامه در ورودی‌ها به دنبال عناوین ستون می‌گردد؛ قالب و ستون‌های لازم را از فایل‌های اصلی سامانه حفظ کنید. فایل‌های نمونهٔ واقعی در این بسته قرار نگرفته‌اند تا اطلاعات عملیاتی افشا نشود.
